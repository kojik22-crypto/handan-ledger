# handan-ledger ｜ 判断台帳

132haの農業法人理事が、自分の確定知見の中でも特に意味あるものを、
撤回条件つきで公開し、定期検証の結果を追記し続ける実験ノート。

## これは何か

経営や人生の判断は、結果だけ見ても学びにならない。
良い判断ほど「何も起きない」ので、後から振り返ると見えなくなる。
だからここでは、自分が"動かさない"と決めた確定知見を、
「何を見たらこれを捨てるか（撤回条件）」とセットで公開する。
そして定期的に現実に当て直し、生き延びたか・書き換わったかを追記していく。

外した記録も消さない。むしろ撤回した瞬間こそ、いちばん学びがある。

## 3つのルール

1. 違和感スコアを添える … その知見に残る引っかかりを0〜5で明示する。確信度の自己申告。
2. 撤回条件を事前に書く … 「これを見たら、この知見を捨てる」を先に明文化する。後出しを構造的に封じる。
3. 追記オンリー・書き換えない … 一度コミットした本文は編集・削除しない。
   再検証は同じファイルに足すだけ。track recordはGitのタイムスタンプが証明する。

## なぜやるか

知見の質は、当たったかどうかでは測れない。
「捨てる条件を先に言えるか」「定期検証を生き延びたか」——そこにしか出ない。
これは自分への規律であり、同じ立場の人への一次資料でもある。

## 書いている人

岐阜の農事組合法人（水稲・麦・大豆ほか132ha／359圃場）の理事。
事務職（会計）から農業経営へ越境し、農業オペレーション×管理会計×データ分析を
一人の中で同時に持つことを試している。

## 注意

ここは助言ではない。一当事者の判断記録であり、再現性も正しさも保証しない。
特定の組織・個人を不利にする情報、守秘義務の対象は一切置かない。
